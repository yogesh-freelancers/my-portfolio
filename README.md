# My Portfolio

Responsive personal portfolio website built with React.js showcasing my projects, skills, and resume.

## 🌐 Live Demo
Visit the live portfolio: [https://yogesh-freelancers.github.io/my-portfolio](https://yogesh-freelancers.github.io/my-portfolio)

## 🚀 Features
- Fully responsive design
- Smooth animations with Framer Motion
- Project showcase
- Skills section
- Contact information
- Optimized for all devices

## 🛠️ Tech Stack
- **React** 19.2.5
- **Framer Motion** 12.38.0 (for animations)
- **React Scripts** 5.0.1
- **CSS3** for styling
- **GitHub Pages** for deployment

## 📦 Installation

1. Clone the repository:
```bash
git clone https://github.com/yogesh-freelancers/my-portfolio.git
cd my-portfolio
```

2. Install dependencies:
```bash
npm install
```

3. Start the development server:
```bash
npm start
```

The application will open at `http://localhost:3000`

## 🏗️ Build & Deployment

### Build for production:
```bash
npm run build
```

### Deploy to GitHub Pages:
```bash
npm run deploy
```

The `predeploy` script automatically runs the build before deployment.

### Manual GitHub Pages Configuration:
1. Go to repository Settings → Pages
2. Select "Deploy from a branch"
3. Choose "main" branch and "/" (root) folder
4. Click Save
